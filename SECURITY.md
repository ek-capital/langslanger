# Security policy

LangSlanger is experimental research software and is not supported for
production use.

Do not report vulnerabilities in a public issue. Use GitHub's private
vulnerability reporting for `ek-capital/langslanger` so maintainers can assess
the report before disclosure.

For security issues in unchanged upstream SGLang code, also follow the upstream
project's security process. Do not send LangSlanger secrets, model weights,
private prompts, traces, or replay capsules with a report unless a maintainer
provides an approved private transfer method.
