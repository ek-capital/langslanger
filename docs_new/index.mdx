LangSlanger is Kinetic Capital's experimental, performance-first,
SGLang-compatible research fork. It is not production software.

Use LangSlanger to measure a serving bottleneck, attribute it to model
architecture and implementation source, capture the smallest useful replay
boundary, and validate an optimization against the same workload and topology.

## What stays compatible

Existing `sglang` commands, Python imports, environment variables, metrics, and
API schemas remain the compatibility contract. LangSlanger-specific controls use
the `langslanger` or `LANGSLANGER_*` namespace.

## Documentation boundary

These pages cover only LangSlanger installation, profiling, and experiment
practice. Use the [upstream SGLang documentation](https://docs.sglang.io/) for
general serving, model, and API guidance.
